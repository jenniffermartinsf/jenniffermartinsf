## 👨🏻‍💻 About me

I’m a Mobile Engineer with 3 years of professional experience, specialized in building Android and iOS applications with React Native and TypeScript, working on production products with a strong focus on performance, architecture, scalability, and user experience.

Currently, I work on the continuous evolution of a mobile application used daily by 25,000+ users. Some of my key contributions include modernizing a legacy JavaScript codebase to TypeScript while introducing a modular architecture, reducing application loading time by approximately 80%, and decreasing the latency of an AI-powered Tutor by around 90%. I also investigated and resolved a critical memory management issue that caused the application to crash during video lessons. These and other improvements contributed to increasing the app’s store rating from 1.8 to 4.7 stars. 
 
My work goes beyond building interfaces. I contribute across the mobile development lifecycle, including software architecture and modularization, REST API integrations, state management, automated testing, observability, CI/CD, and application distribution. My experience includes React Native, TypeScript, Expo, Expo Router, React Query, Zustand, React Hook Form, Zod, Jest, React Native Testing Library, GitHub Actions, Xcode, Sentry, and CI/CD. 

In previous roles, I also worked with Clean Architecture, SOLID principles, reusable components, code reviews, and CI/CD, while contributing to the resolution of more than 40 critical bugs, improving application stability and user experience. 

Working with React Native has also led me to develop a deeper interest in understanding iOS beyond the cross-platform layer. I’m currently expanding my expertise into native iOS development with Swift, SwiftUI, and UIKit, building personal projects and exploring the Apple ecosystem as I work toward becoming an iOS Developer. My goal is to combine my professional mobile engineering background with increasingly deep knowledge of the native iOS platform.
